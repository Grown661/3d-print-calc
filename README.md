# 3D-Druck Kostenrechner

Was kostet ein 3D-Druck wirklich? Dieser Rechner ermittelt Material-, Strom- und Gesamtkosten inklusive Verkaufspreis mit Marge – komplett im Browser.

## Features

- Materialkosten aus **Gewicht (g)** direkt aus dem Slicer, oder aus **Länge + Durchmesser + Dichte**
- Dichte-Presets für PLA, PETG und ABS
- Stromkosten aus Druckdauer × Drucker-Leistung × Strompreis
- Verschleiss- / Fehldruck-Pauschale
- Verkaufspreis-Vorschlag mit einstellbarer Marge
- Letzte Eingaben werden automatisch gespeichert (localStorage)
- Läuft komplett offline, keine Abhängigkeiten

## Stack

Vanilla JavaScript, HTML, CSS – keine Build-Kette, keine Libraries.

## Setup & Start

```
index.html im Browser öffnen – fertig.
```
